# JavaScript Angular Map Project

An Angular-based web application demonstrating modern mapping capabilities and JavaScript programming concepts. This project showcases the integration of mapping services with Angular framework components.

## 🎯 Project Overview

This is a JavaScript programming project built with Angular CLI that demonstrates:
- Modern Angular application structure and best practices
- Component-based architecture and TypeScript implementation
- Integration of mapping services and geolocation features
- Responsive web design principles
- Modern JavaScript/TypeScript development workflows

## 📋 Prerequisites

Before running this project, make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v14 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Angular CLI](https://angular.io/cli) (v12 or higher)

## 🛠️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/nmneedham/JavaScript-Angular-Map-Project.git
   cd JavaScript-Angular-Map-Project
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   ng serve
   ```

4. **Open your browser**
   Navigate to `http://localhost:4200`
